Lecture 4

Keywords

perceptron, exponential family, generalized linear models, softmax regression, cross-entropy

Lecture video: Lecture 4: Perceptron and Generalized Linear Model · 1:22:02

Based on the lecture by Anand Avati — CS229, Stanford University, Autumn 2018.

Lectures 2 and 3 derived linear regression and logistic regression separately, and both ended with the same update, θj:=θj+α (y−hθ(x)) xj\theta_j := \theta_j + \alpha\,(y - h_\theta(x))\,x_jθj​:=θj​+α(y−hθ​(x))xj​. This lecture, given by Anand Avati while Ng was away, explains why. Both models are instances of a generalized linear model: pick a distribution for yyy from the exponential family, let its natural parameter be a linear function of xxx, and the hypothesis, the likelihood and the update all follow — the same update every time, with only hθh_\thetahθ​ changing. The sigmoid, which lecture 3 introduced without justification, falls out of this recipe once yyy is assumed Bernoulli. The lecture opens with the perceptron, which has the same update for a different reason, and closes with softmax regression, which extends logistic regression to many classes.

4.1 The perceptron

1:35 The perceptron replaces logistic regression’s sigmoid with a hard threshold, g(z)=1g(z) = 1g(z)=1 if z≥0z \ge 0z≥0 and 000 otherwise, so hθ(x)=g(θ⊤x)h_\theta(x) = g(\theta^\top x)hθ​(x)=g(θ⊤x) outputs a label rather than a probability. The update is the one from lecture 3, written for one example at a time:

θ:=θ+α(y(i)−hθ(x(i)))x(i).(4.1) \theta := \theta + \alpha \left(y^{(i)} - h_\theta(x^{(i)})\right) x^{(i)} . \tag{4.1}θ:=θ+α(y(i)−hθ​(x(i)))x(i).(4.1)

Avati reads it from the inside out. Since yyy and hθ(x)h_\theta(x)hθ​(x) are both 0 or 1, the bracket can take only three values: 0 when the prediction is right, so nothing happens; +1+1+1 when a positive example was called negative; and −1-1−1 in the opposite case. A correctly classified example therefore leaves θ\thetaθ alone, and a misclassified one adds or subtracts a multiple of itself.

7:27 The geometric picture makes that rule look inevitable rather than arbitrary. The decision boundary θ⊤x=0\theta^\top x = 0θ⊤x=0 is the line perpendicular to θ\thetaθ, and θ⊤x\theta^\top xθ⊤x is positive for inputs on the side θ\thetaθ points toward. We want θ\thetaθ to have a positive dot product with the positive examples and a negative one with the negative examples — to be similar to the first and dissimilar to the second. When a positive xxx lands on the wrong side, the most naive way to make θ\thetaθ more like xxx is to add a bit of xxx to it. That rotates θ\thetaθ toward xxx, and the boundary rotates with it (Figure 4.1).

The lecture calls α\alphaα “some small learning rate”, but for the perceptron as usually run it has no effect at all. Starting from θ=0\theta = 0θ=0, every update adds ±αx(i)\pm\alpha x^{(i)}±αx(i), so θ\thetaθ is always α\alphaα times a sum of examples, and the sign of θ⊤x\theta^\top xθ⊤x — the only thing the prediction depends on — does not depend on α\alphaα. The generator checks this: on a separable set of 40 points, α=1\alpha = 1α=1 and α=0.001\alpha = 0.001α=0.001 make the same 8 mistakes in the same order and finish with parameter vectors that differ by exactly the factor of 1000. The learning rate starts to matter only if it changes over time, which is where a student question led.

12:39 Asked why the perceptron is not used in practice, Avati gives two reasons. It has no probabilistic interpretation: it draws a boundary but says nothing about how confident it is. And it has a famous limitation. The perceptron was celebrated in the late 1950s as a model of the brain (Rosenblatt, 1958); the 1969 book Perceptrons by Marvin Minsky and Seymour Papert (the lecture remembers it as a paper by Minsky) set out what a single linear threshold unit cannot compute, and the smallest example is XOR — two positive and two negative points at the corners of a square, diagonally opposite, which no line separates. Interest in the model collapsed afterwards.

13:39 A second question asked when to stop training. If the data are linearly separable, the answer is a theorem the lecture does not state: the perceptron stops making mistakes after finitely many updates. If every ∥x(i)∥≤R\lVert x^{(i)} \rVert \le R∥x(i)∥≤R and some unit vector uuu separates the classes with margin γ\gammaγ, the number of mistakes is at most (R/γ)2(R/\gamma)^2(R/γ)2, whatever the order of the examples (Novikoff, 1962). On the generator’s 40 points the bound is 55 and the perceptron makes 8. If the data are not separable, it never settles — on XOR it is still making mistakes on all four points in the thousandth pass — so Avati’s practical advice is to anneal: shrink α\alphaα with every example until θ\thetaθ stops moving much. That is exactly the case where α\alphaα is no longer irrelevant, since later updates then count for less than earlier ones.

13:31 Avati also offers the cleanest way to place the perceptron beside the previous lecture: logistic regression is a soft version of it. The step function is the limit of g(kz)=1/(1+e−kz)g(kz) = 1/(1 + e^{-kz})g(kz)=1/(1+e−kz) as the slope kkk grows (Figure 4.2); at k=12k = 12k=12 the two already differ by less than 0.003 everywhere outside ∣z∣<0.5|z| < 0.5∣z∣<0.5. What the sigmoid buys in exchange for that softness is a likelihood, and with it everything that follows.

4.2 The exponential family

14:53 The exponential family is a class of distributions with convenient mathematics, and it is the bridge to generalized linear models. A distribution belongs to it if its density (or, for discrete yyy, its probability mass function) can be written

p(y;η)=b(y)exp⁡ ⁣(η⊤T(y)−a(η)).(4.2) p(y; \eta) = b(y) \exp\!\left( \eta^\top T(y) - a(\eta) \right) . \tag{4.2}p(y;η)=b(y)exp(η⊤T(y)−a(η)).(4.2)

Avati names each piece. The variable is called yyy, not xxx, on purpose: these distributions will model the output of a supervised problem, and xxx enters only when the model is built. η\etaη is the natural parameter. T(y)T(y)T(y) is the sufficient statistic, in the statistician’s sense, but for every distribution in this course T(y)=yT(y) = yT(y)=y, and the lecture tells the reader to make that substitution and move on. b(y)b(y)b(y) is the base measure, which may depend only on yyy; and a(η)a(\eta)a(η) is the log-partition function, which may depend only on η\etaη. In most of the course yyy and η\etaη are scalars; softmax will need a vector η\etaη.

18:48 The name of aaa explains its job. Moving it out of the exponent gives p(y;η)=b(y) eηT(y)/ea(η)p(y;\eta) = b(y)\, e^{\eta T(y)} / e^{a(\eta)}p(y;η)=b(y)eηT(y)/ea(η), so ea(η)e^{a(\eta)}ea(η) is the normalising constant — the partition function — that makes the density integrate to one, and a(η)a(\eta)a(η) is its log. The condition is not a side constraint on aaa; it determines it. Once bbb and TTT are fixed,

4.3 Why the exponential family is convenient

33:10 Three properties make the family worth the trouble, and Avati states them without proof — they are an exercise in the first problem set. First, maximum likelihood in the natural parameter is a concave problem, so it has no spurious local maxima; the negative log-likelihood, its cost-function form, is convex. Second and third, the log-partition function produces the moments by differentiation:

E[y;η]=∂a∂η,Var⁡[y;η]=∂2a∂η2.(4.4) \mathbb{E}[y; \eta] = \frac{\partial a}{\partial \eta} , \qquad \operatorname{Var}[y; \eta] = \frac{\partial^2 a}{\partial \eta^2} . \tag{4.4}E[y;η]=∂η∂a​,Var[y;η]=∂η2∂2a​.(4.4)

35:08 The point Avati makes about these is practical: computing a mean or a variance normally means integrating against the density, and here it means differentiating a single function, which is far easier. For the Bernoulli, a′(η)=1/(1+e−η)=ϕa'(\eta) = 1/(1+e^{-\eta}) = \phia′(η)=1/(1+e−η)=ϕ and a′′(η)=ϕ(1−ϕ)a''(\eta) = \phi(1-\phi)a′′(η)=ϕ(1−ϕ); for the Gaussian, a′=η=μa' = \eta = \mua′=η=μ and a′′=1a'' = 1a′′=1; for the Poisson, both derivatives are eη=λe^\eta = \lambdaeη=λ, the textbook fact that a Poisson’s mean equals its variance. The generator checks all three by computing a′a'a′ and a′′a''a′′ by finite differences and the mean and variance by summing over the support. The first property follows from the third: a variance is never negative, so aaa is convex, and the log-likelihood log⁡b(y)+ηy−a(η)\log b(y) + \eta y - a(\eta)logb(y)+ηy−a(η) is linear minus convex, which is concave. 36:06 When η\etaη is a vector, as for a Gaussian with unknown variance, a student asked how this generalises; the gradient of aaa gives the mean of T(y)T(y)T(y) and its Hessian the covariance.

4.4 Generalized linear models

36:35 A generalized linear model attaches the inputs to an exponential-family distribution, and the lecture frames it as three design choices.

  1. y∣x;θy \mid x; \thetay∣x;θ is distributed according to some member of the exponential family, with natural parameter η\etaη.
  2. The natural parameter is linear in the input: η=θ⊤x\eta = \theta^\top xη=θ⊤x, with θ,x∈Rn\theta, x \in \mathbb{R}^nθ,x∈Rn.
  3. At test time, the prediction for xxx is the mean of that distribution: hθ(x)=E[y∣x;θ]h_\theta(x) = \mathbb{E}[y \mid x; \theta]hθ​(x)=E[y∣x;θ].

38:36 The first choice is the modelling decision, and it is dictated by what kind of quantity yyy is. Real-valued outputs such as house prices call for a Gaussian; binary labels for a Bernoulli; counts — non-negative integers, such as the number of visitors to a website — for a Poisson; positive reals such as a volume or the time until an event for a gamma or an exponential. Avati warns that the exponential distribution and the exponential family are different things, though the first is a member of the second, and the list ends with distributions over probabilities, the beta and the Dirichlet, which mostly appear in Bayesian statistics. Whether a GLM is a classifier or a regressor is therefore not a property of GLMs at all: it is decided by the distribution put in the first slot.

42:55 The picture to keep in mind has two halves. On the left is a linear model: xxx goes in, a learnable θ\thetaθ multiplies it, and out comes a number. On the right is a distribution from the exponential family, and that number becomes its natural parameter. 45:40 Only θ\thetaθ is learned. A student asked whether training adjusts the distribution’s parameters, and the answer separates two uses of the word “parameter”: η\etaη is not a variable that gradient descent touches, it is the output of the linear model for one particular xxx. Training is maximum likelihood over θ\thetaθ,

max⁡θ  ∑i=1mlog⁡p ⁣(y(i);η=θ⊤x(i)), \max_\theta \; \sum_{i=1}^m \log p\!\left(y^{(i)}; \eta = \theta^\top x^{(i)}\right) , θmax​i=1∑m​logp(y(i);η=θ⊤x(i)),

which is concave in θ\thetaθ because it is concave in η\etaη and η\etaη is linear in θ\thetaθ.

48:46 Here the recipe pays off. One would expect each new distribution to need its own algebra: write ppp as a function of θ⊤x\theta^\top xθ⊤x, differentiate, simplify. It does not, because for every GLM built this way the stochastic gradient-ascent update is

θj:=θj+α(y(i)−hθ(x(i)))xj(i),(4.5) \theta_j := \theta_j + \alpha \left( y^{(i)} - h_\theta(x^{(i)}) \right) x^{(i)}_j , \tag{4.5}θj​:=θj​+α(y(i)−hθ​(x(i)))xj(i)​,(4.5)

with hθ(x)=a′(θ⊤x)h_\theta(x) = a'(\theta^\top x)hθ​(x)=a′(θ⊤x) the only thing that changes. The derivation is one line: the log-likelihood of one example is log⁡b(y)+θ⊤x y−a(θ⊤x)\log b(y) + \theta^\top x\, y - a(\theta^\top x)logb(y)+θ⊤xy−a(θ⊤x), and its gradient is (y−a′(θ⊤x)) x(y - a'(\theta^\top x))\, x(y−a′(θ⊤x))x, which by Equation 4.4 is (y−hθ(x)) x(y - h_\theta(x))\, x(y−hθ​(x))x. This is why linear regression, logistic regression and Poisson regression share an update: the first is the Gaussian GLM with h=θ⊤xh = \theta^\top xh=θ⊤x, the second the Bernoulli with h=1/(1+e−θ⊤x)h = 1/(1+e^{-\theta^\top x})h=1/(1+e−θ⊤x), the third the Poisson with h=eθ⊤xh = e^{\theta^\top x}h=eθ⊤x. The generator checks the expression against a numerical gradient of the log-likelihood for all three.

“Every GLM” carries a qualification the lecture leaves implicit: the identity holds because the natural parameter itself is set to θ⊤x\theta^\top xθ⊤x. A model that instead connects θ⊤x\theta^\top xθ⊤x to the mean through some other function does not inherit it. The probit model of lecture 3, P(y=1∣x)=Φ(θ⊤x)P(y = 1 \mid x) = \Phi(\theta^\top x)P(y=1∣x)=Φ(θ⊤x) with Φ\PhiΦ the standard normal CDF, is a Bernoulli model with exactly the same shape, and the update that looks right for it — Equation 4.5 with h=Φ(θ⊤x)h = \Phi(\theta^\top x)h=Φ(θ⊤x) — is not its gradient: at a test point on synthetic data it has the right direction but a length off by 41 percent. That would be harmless if it only rescaled the step, but it also moves the place where the step vanishes. Iterated to convergence, the look-alike update stops at θ=(−0.200,0.697)\theta = (-0.200, 0.697)θ=(−0.200,0.697), while the probit maximum-likelihood estimate is (−0.210,0.707)(-0.210, 0.707)(−0.210,0.707). The two links are close, so the error is small, but the algorithm is now solving a different equation from the one it claims to.

50:43 For batch training, sum the update over the examples. Asked about Newton’s method, Avati calls it probably the most common way to fit a GLM, provided the number of features is below a few thousand, so that the Hessian is affordable — the same rule of thumb Ng gave in lecture 3. Concavity is what makes it safe: on a Poisson regression with 200 synthetic counts, Newton’s method reaches the maximum in 7 iterations, at the same θ\thetaθ that plain gradient ascent eventually finds.

4.5 Three parametrisations

52:03 The lecture pauses on terminology, because a GLM has three sets of numbers called parameters and they are easy to confuse (Figure 4.3). The model parameters θ\thetaθ are what learning adjusts. The natural parameter η\etaη is the linear model’s output, one per example. The canonical parameters are the ones the distribution is usually written in: ϕ\phiϕ for a Bernoulli, μ\muμ (and σ2\sigma^2σ2) for a Gaussian, λ\lambdaλ for a Poisson. The step from θ\thetaθ to η\etaη is linear by design choice 2. The step from η\etaη to the mean has a name: g(η)=E[y;η]=a′(η)g(\eta) = \mathbb{E}[y;\eta] = a'(\eta)g(η)=E[y;η]=a′(η) is the canonical response function, and its inverse g−1g^{-1}g−1 is the canonical link function.

56:23 With the vocabulary in place, logistic regression stops being a choice and becomes a consequence. For a binary label the natural distribution is the Bernoulli; design choice 3 says the hypothesis is its mean, hθ(x)=ϕh_\theta(x) = \phihθ​(x)=ϕ; and Equation 4.3 says ϕ=1/(1+e−η)\phi = 1/(1 + e^{-\eta})ϕ=1/(1+e−η) with η=θ⊤x\eta = \theta^\top xη=θ⊤x. Lecture 3 pulled the logistic function “out of thin air” because it squashes the real line into (0,1)(0, 1)(0,1). Here, as Avati puts it, it simply pops out: the sigmoid is the canonical response function of the Bernoulli. The same steps applied to the Gaussian return hθ(x)=θ⊤xh_\theta(x) = \theta^\top xhθ​(x)=θ⊤x, ordinary least squares.

The idea and the name are due to Nelder and Wedderburn (1972), who showed that one fitting procedure covered regression models that had been treated separately.

4.6 What the assumptions say about the data

1:00:03 Avati’s last pass over GLMs draws the assumptions as a story about how the data were generated. For the Gaussian, take a line θ⊤x\theta^\top xθ⊤x; at every xxx, stand a unit-variance Gaussian on the line; and draw each training yyy from the Gaussian above its xxx (Figure 4.4, left). Learning runs the story backwards: each choice of θ\thetaθ is a different line, and maximum likelihood picks the line from whose Gaussians the observed points were most likely to have come.

1:04:50 For classification the story has one more step. The line now gives η\etaη, which can be any real number; passing it through the sigmoid gives ϕ\phiϕ, the probability that y=1y = 1y=1 at that xxx; and each label is a coin flip with that bias, so labels are mostly 0 where the curve is low and mostly 1 where it is high (Figure 4.4, right). Logistic regression asks which θ\thetaθ would have produced a sigmoid from which these labels were most likely drawn.

4.7 Softmax regression

1:07:58 Softmax regression extends logistic regression to kkk classes. The notes present it as one more GLM, built on the multinomial distribution; the lecture deliberately takes another route and presents it as cross-entropy minimisation, an interpretation worth having because it is how classifiers with thousands of classes are usually described.

1:11:04 The labels are one-hot vectors: a vector of kkk zeros with a single 1 in the position of the correct class. Where logistic regression had one parameter vector, softmax has one per class, θ1,…,θk\theta_1, \dots, \theta_kθ1​,…,θk​, which together form an n×kn \times kn×k matrix.
